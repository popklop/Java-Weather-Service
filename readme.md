Приложение для получения данных о погоде через API Яндекс Погоды.

Приложение выводит полный JSON-ответ сервера, текущую температуру и среднюю температуру за указанное количество дней.

## Требования

- Java 17 или выше
- Maven
- API-ключ Яндекс Погоды

## Получение API-ключа

1. Перейти на https://yandex.ru/pogoda/b2b/console/home
2. Подключить подходящий тариф API.
3. Получить API-ключ.

## Запуск

Перед запуском необходимо установить API-ключ в переменную окружения.

**Windows PowerShell:**

```powershell
$env:YANDEX_WEATHER_API_KEY="YOUR_API_KEY"
```

**Linux:**

```bash
export YANDEX_WEATHER_API_KEY="YOUR_API_KEY"
```

Сборка и запуск:

```bash
mvn clean compile exec:java
```

По умолчанию используются координаты Москвы и прогноз на 5 дней.

## Аргументы запуска

Можно указать собственные координаты и количество дней:

```bash
mvn clean compile exec:java "-Dexec.args=55.75 37.62 7"
```

Формат аргументов:

```text
широта долгота количество_дней
```

Количество дней должно быть от 1 до 7.

## Пример

Запрос погоды для Санкт-Петербурга на 3 дня:

```bash
mvn clean compile exec:java "-Dexec.args=59.93 30.31 3"
```
